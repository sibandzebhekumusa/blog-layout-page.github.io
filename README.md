# blog-layout-page.github.io
This is my responsive blog layout page. 

☕ The Daily Roast Blog

A simple, cozy coffee shop blog made with HTML and CSS. It shares coffee news, brewing tips, and shop hours.

What's Inside
Warm Coffee Colors: Uses cream and espresso brown tones for a cozy feel.
Easy-to-Read Layout: Keeps the page centered and puts each blog post inside its own clean white card.
Simple Structure: Uses basic HTML tags (<header>, <nav>, <main>, <article>, and <footer>) styled with an external CSS file.

Files
index.html - The webpage content and layout.
 style.css - The colors, fonts, and card designs.

How to Open It
1. Download the files into the same folder.
2. Double-click index.html to view it in your web browser.
